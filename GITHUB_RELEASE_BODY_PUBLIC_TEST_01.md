# 093 Drift HUD - Public Test 01

FH6 / Forza Horizon telemetry-based drift HUD.

## Download
Download `093_Drift_HUD_Public_Test_01_WINDOWS.zip` from Assets.

## Start
1. Extract the ZIP.
2. Open the extracted folder.
3. Double-click `START_093_DRIFT_HUD.bat`.

No Python installation is required.

## FH6 / Forza Horizon Data Out
`127.0.0.1:5300`

## SimHub passthrough
`127.0.0.1:8001`

## Exit HUD
`Ctrl + Shift + Q`

## Display profiles
- 1440p starts in `1440P STREAM`.
- 1080p automatically starts in the dedicated `1080P STREAM` layout.
- Press `Ctrl + F9` to switch HUD profiles.

This is a public test build. Feedback and bug reports are welcome.
