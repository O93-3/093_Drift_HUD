Auto 1080P safe profile fix

Public Test 01 safety fix:
- If the display height is below 1200px, the HUD automatically starts in 1080P STREAM.
- This prevents 1440p public layout placement from being awkward or partially off-screen on 1080p displays.
- 1440p users keep the normal 1440P STREAM startup.
- Ctrl + F9 still cycles HUD profiles.
- Ctrl + Shift + Q exits the HUD.
